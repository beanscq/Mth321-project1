# Robertson 刚性 ODE —— 数值方法核心

对一个**刚性**常微分方程初值问题，从零实现三种定步长积分器，
用高精度参考解检验它们的收敛阶、稳定步长上界和四道正确性诊断。

问题取自 Robertson 化学动力学（三组分、两个时间尺度相差约 `1e8`）：

```
y1' = -0.04*y1 + 1e4*y2*y3
y2' = +0.04*y1 - 1e4*y2*y3 - 3e7*y2**2        y(0) = (1, 0, 0),  t ∈ [0, 40]
y3' = +3e7*y2**2
```

## 目录

| 文件 | 作用 |
|---|---|
| `model.py` | 问题定义：右端项 `f`、解析 Jacobian、守恒量、非零特征值。不含任何数值方法 |
| `solvers.py` | 三种方法：显式 Euler / RK4 / 隐式 Euler(Newton)；公共步进循环 + 三次 Hermite 稠密输出 |
| `analysis.py` | 高精度参考解、四道诊断、实测收敛阶、稳定步长上界 |
| `demo.py` | 一键跑通全部结论，打印报告并出两张图 |
| `requirements.txt` | 依赖：numpy / scipy / matplotlib |

## 运行

```bash
pip install -r requirements.txt
python demo.py            # 完整版，约 2 分钟
python demo.py --quick    # 快速版，约 40 秒（收敛阶梯只跑 3 层）
```

输出在终端；两张图写到 `results/`（生成物，已在 `.gitignore` 中忽略）。

## 这个程序能得出什么

`demo.py` 分七节，下面每一节的数字都是程序自己算出来的，不是写死的。

**1. 模型自检** —— 在守恒面上随机取 200 个状态，验证 `(1,1,1)·f ≡ 0`
（相对量级到舍入级），并用中心差分核对解析 Jacobian。

**2. 刚性有多强** —— t = 40 处 J 的两个非零特征值约为
`-3392.79` 和 `-0.0214`，刚性比 `S ≈ 1.58e5`。程序同时指出
`|Re λ|_max = 3392.79` 出现在 **t = 40 附近**而不是初值处，
所以估步长必须用整条轨迹上的最大值。

**3. 稳定步长上界：理论 vs 实测**

| 方法 | 负实轴稳定区间端点 | 冻结谱上界 h < |
|---|---|---|
| 显式 Euler | 2.0000 | 5.895e-4 |
| RK4 | 2.7853 | 8.209e-4 |
| 隐式 Euler | ∞（A 稳定） | 不受谱限制 |

程序随后真的去扫步长并把边界对分收窄：显式 Euler 的实测崩溃阈值约 `6.22e-4`，
比冻结谱的 5.895e-4 高约 6% —— 因为 `|λ|_max` 只在 t 接近 40 的最后几步才出现，
最快模态此前一直被强阻尼，末段已没有足够时间把它长到发散判据。
所以冻结谱是个**充分但略保守**的估计。

**4. 实测收敛阶**（误差对比高精度参考解，log-log 最小二乘）

| 方法 | 实测阶 | 理论阶 |
|---|---|---|
| 显式 Euler | ≈ 1.08 | 1 |
| RK4 | ≈ 4.27 | 4 |
| 隐式 Euler | ≈ 1.00 | 1 |

两个实现细节决定了这里能不能做对：

* **稠密输出必须用三次 Hermite**（用步两端的 `y` 和 `f` 构造，误差 `O(h^4)`）。
  若图省事用线性插值，插值误差 `O(h^2)` 会把 RK4 的实测阶直接压到 2。
* **误差掉到参考解自身不确定度量级的层必须剔除**。穿过"参考解地板"的数据拟合出来的
  收敛阶没有意义，这是最常被忽略的一步。

**5. 四道诊断必须分开记** —— 取 `h = 3e-3`（远大于显式方法的稳定上界）：

| 方法 | 走到 | 守恒残差 | 最低浓度 | 误差 |
|---|---|---|---|---|
| 显式 Euler | 0.0120 | 1.1e-13 | **-921.8** | **1.08e10** |
| RK4 | 0.0030 | 0.0 | -1.03e-2 | 1.40e0 |
| 隐式 Euler | 40.0 | 3.1e-15 | 0.0 | 2.21e-5 |

显式 Euler 这一行是全部要点：**守恒残差 1e-13 看着满分，但最低浓度是负的 -921.8、
误差 1e10**。如果只查守恒，这份结果会被放行。原因不是巧合而是定理：

```
(1,1,1)^T f ≡ 0   ⇒   (1,1,1)^T J ≡ 0
                  ⇒   每个 Newton 迭代精确保持 y1+y2+y3（与停止容差无关）
```

守恒量是任何相容格式的代数恒等式，它**结构上不可能失败**，所以它永远不能用来判断精度。
真正能抓错的是另外三道：非负性、全状态误差、终点值。

反过来看隐式 Euler：同一个步长下它一路走到 t = 40，但误差仍是 `O(h)`（一阶方法）。
**「没崩」是稳健性结论，不是精度结论。**

**6. 终点值 y2(40)** —— 自己的参考解给出

```
y2(40) = 9.185534764558e-06
```

与题面给的 `9.1855e-06` 一致（题面只给到 5 位有效数字）。程序随后列出
各方法在不同步长下能"承认"到几位。

**7. 出图** —— `results/convergence.png`（三种方法的误差-步长曲线，附理论斜率虚线）、
`results/stiff_transient.png`（参考解的 y2 快瞬态 + 显式 Euler 崩溃时的轨迹）。

## 实现上的几个取舍

* **显式 Euler 和 RK4 不重新求 `f` 做稠密输出。** 步节点上的 `f` 全部是"顺手捡的"：
  RK4 的 `k1` 就是它，显式 Euler 下一步的第一次求值就是它，隐式 Euler 的 Newton
  最后一次残差求值已经算过。所以稠密输出的右端项额外开销恰好为 0，
  `rhs_calls` 这个计数器就是真实调用次数。
* **Jacobian 用解析式，不用有限差分。** 隐式方法每步都要用它，差分近似会把
  Newton 的二次收敛拖成线性。
* **Newton 的收敛判据是 `||G||_inf` 而不是 `||dx||`。** 因为
  `sum G(z) = sum(z) - sum(y_n)`，残差容差可以直接翻译成守恒残差的界，而 `||dx||` 不能。
* **参考解用 Radau 且 `atol` 逐分量给** `[1e-14, 1e-20, 1e-14]`：`y2` 生活在
  `1e-5 ~ 1e-10`，与 `y1`、`y3` 差十几个量级，单一标量 `atol` 要么浪费精度要么把 `y2` 抹平。
* **网格端点是写死的字面值。** `10**log10(40.0)` 在不同 libm 下可能是
  `39.99999999999999` 或 `40.000000000000007`，末点一旦越过 `t_max`，
  `solve_ivp` 会用 "Values in `t_eval` are not within `t_span`" 拒掉整个网格 ——
  网格不能是平台相关的。

## 依赖环境

`numpy` / `scipy` / `matplotlib`。`scipy` 只用在 `analysis.reference_solution()`
（作为高精度参照），三种积分器本身不依赖它。
